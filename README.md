# MediaGen Pro

Клиентское веб-приложение на **React 19**, **TypeScript** и **Vite** для визуальной сборки обложек под **Instagram** и **веб** (OG 1200×628).

## Запуск

```bash
npm ci
npm run dev
```

Сборка и превью продакшена:

```bash
npm run build
npm run preview
```

## Скрипты

- `npm run lint` — ESLint
- `npm run build` — проверка TypeScript и production-сборка

Состояние редактора сохраняется в `localStorage` (ключ `mediagen_pro_state`).
